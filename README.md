This Repo is my development of Generative AI using transformer architectures.
To better understand and build the transformer , it is a good approach to start with what word2vector and how are they classified ? Then learn about the RNN .

Start with Assignment -1 in the main repo.
Move to Assignment-2,3 to clearly understand the gaps between RNN and its context memory (KV cache). This would build a good foundation to dive into transformers and its architecture.

Then you can explore how can you create your own GPT.

GPT-3 is a functional code with 2 decoder blocks for better accuracy of generative AI build for responses from the user.
